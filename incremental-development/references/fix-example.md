# 修复案例：搜索输入只有空格时显示全部任务

## 输入与验收

用户请求：“任务列表搜索框输入几个空格就显示空列表。希望它和不输入时一样显示全部任务，顺便保持正常关键词搜索。”

这是已有行为的小修复，目标和验收已明确，可直接处理，无需补完整 PRD。验收边界：空字符串或纯空格返回全部任务；关键词首尾空格不影响匹配；未匹配返回空数组；保留原来的区分大小写规则。

## 原因与修改

原函数仅把空字符串视为“没有查询”。三个空格仍会进入标题匹配，通常匹配不到任务。先去除查询首尾空格，再沿用现有匹配逻辑即可；不扩展为模糊搜索或改变大小写规则。

预期 diff 如下，仅代表示意改动：

```diff

--- a/src/filterTasks.js
+++ b/src/filterTasks.js
@@ -1,4 +1,5 @@
 export function filterTasks(tasks, query) {
-  if (!query) return tasks;
-  return tasks.filter(task => task.title.includes(query));
+  const keyword = query.trim();
+  if (!keyword) return tasks;
+  return tasks.filter(task => task.title.includes(keyword));
 }
```

该写法假设调用方始终提供字符串。实际项目若允许 `null` 或其他类型，应先核实接口约定，不能从这个案例直接套用。
